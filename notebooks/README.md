# Notebooks — data analysis & preprocessing

| Notebook | Purpose |
|----------|---------|
| `data_analysis.ipynb` | Explore the Flipkart fashion dataset, clean it, engineer features and produce the balanced dataset used by the RAG app |
| `fine_tunning.ipynb` | Experiment: fine-tuning a classifier on the preprocessed data (built for a Kaggle GPU runtime) |

## Setup
Same environment as the app, with extras:
```bash
pip install -e ".[notebooks]"        # analysis
pip install -e ".[notebooks,finetune]"  # + fine-tuning (large: torch, transformers)
python -m spacy download en_core_web_sm   # if the notebook asks for it
jupyter lab
```

## Data
The datasets are **not in git** (too large). Put them in this folder:

- `flipkart_fashion_products_dataset.json` — raw data. **Download: `<TODO: add dataset link>`**
- `preprocessed_data.json`, `data_ready.json`, `balanced_data.json` — generated by `data_analysis.ipynb`

The output `balanced_data.json` is copied to `../data/` to feed the app pipeline. The app falls back
to `../data/sample/sample_products.json` when the full dataset is missing.
